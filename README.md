# Bubble Sort (C++)

Bubble sort on an array in C++.

## Features

- Sorts a hard-coded array into ascending order using bubble sort
- Prints the sorted array

## Tech stack

C++

## Getting started

```bash
git clone https://github.com/Matiz009/bubble-sort-cpp.git
cd bubble-sort-cpp
g++ "bubble_sort.cpp" -o bubble_sort && ./bubble_sort
```

## Project structure

```
bubble_sort.cpp   Source code
bubble_sort.exe   Old Windows build
```
